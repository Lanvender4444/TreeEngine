# TreeEngine end-to-end QA — longdoc

- documents: 48, questions: 91 (heldout 91; lookup 91)
- answer model: `stub` (temperature 0, answer context filled to 1000, 2000 tokens from the top 50 anchors, one prompt for every strategy)
- judges: deterministic → semantic (stub-judge; no access to documents) → human audit
- full_context budget: 120,000 tokens
- embeddings: `fastembed:BAAI/bge-small-en-v1.5`; tokens: tiktoken cl100k_base
- judge tokens (evaluation cost, excluded below): 95,607
- retrieval code: frozen retrieval system (2026-10-13 15:40; V0.9: unified anchors (fuse_anchors + absorb_contained before the candidate-pool cut: a NodeAnchor takes over the best fast-path block inside its section and reads around it), embeddable integration, Graph-lite (expansion only adds blocks no other path found; graph_weight=0 default). Default, fts-only, tree blocks-mode and search() outputs identical to V0.8 (42 queries x 2 scopes)); evaluation changed since the freeze: benchmarks/context.py, treeengine/context/builder.py, treeengine/context/resolution.py, treeengine/context/span.py
- evidence geometry: stable (index title: document; pdf structure: auto)
- **STUB MODELS: pipeline test only, accuracy is meaningless**
