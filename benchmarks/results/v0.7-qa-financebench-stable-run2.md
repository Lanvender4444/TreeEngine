# TreeEngine end-to-end QA — financebench

- documents: 84, questions: 150 (heldout 150; domain-relevant 50, metrics-generated 50, novel-generated 50)
- answer model: `deepseek-flash` (temperature 0, answer context filled to 2000, 3000 tokens from the top 50 anchors, one prompt for every strategy)
- judges: deterministic → semantic (deepseek-flash; no access to documents) → human audit
- full_context budget: 120,000 tokens
- embeddings: `fastembed:BAAI/bge-small-en-v1.5`; tokens: tiktoken cl100k_base
- judge tokens (evaluation cost, excluded below): 705,094
- retrieval code: frozen retrieval system (2026-10-12 01:14; V0.7: evidence geometry decoupled from structure geometry (treeengine/blocks: EvidenceBuilder = the structure-free paragraph blocks + offset mapping; EngineConfig.evidence_geometry stable|coupled, index_title document|section); default stable/document; coupled reproduces pre-V0.7 blocks. Re-frozen after the V0.7 runs for a docstring-only change in structure/builder.py)
- evidence geometry: stable (index title: document)
