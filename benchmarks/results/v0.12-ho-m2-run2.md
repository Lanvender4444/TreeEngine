# TreeEngine end-to-end QA — multires2

- documents: 20, questions: 88 (test 88; cross 28, local 30, point 30)
- answer model: `deepseek-flash` (temperature 0, answer context filled to 1000, 2000 tokens from the top 50 anchors, one prompt for every strategy)
- judges: deterministic → semantic (deepseek-flash; no access to documents) → human audit
- full_context budget: 120,000 tokens
- embeddings: `fastembed:BAAI/bge-small-en-v1.5`; tokens: tiktoken cl100k_base
- judge tokens (evaluation cost, excluded below): 1,045,669
- retrieval code: frozen retrieval system (2026-10-16 02:17; V0.12: adaptive context (context/geometry.py + context/adaptive.py): same_section_ratio of the top-10 hits < 0.4 -> broad (raw), else auto; threshold fixed on longdoc dev verdicts; heldout FinanceBench. Default (rrf + auto) outputs identical to V0.8)
- evidence geometry: stable (index title: document; pdf structure: hybrid)
