## Decision point

- tree_lexical+fts: current (auto) 17.3 → reference 28.2 (**+10.9** points); FTS without structure 19.1
- design doc rule: a large gap → structure extraction is the bottleneck, invest in a structure engine; a small gap → tree retrieval's own ceiling is limited, keep the tree as a light navigation / scope tool.
