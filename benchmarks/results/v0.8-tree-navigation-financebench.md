## Reading

- Every lexical tree strategy moves in the right direction on layout / hybrid (tree_lexical +2.8, tree_lexical+fts +1.8 R@5; +2.7 / +2.8 R@2k). The paired changes are few (2–3 questions of 55), so no single change is significant.
- The gap to the reference tree stays large: tree_lexical+fts layout 18.2 / hybrid 20.9 vs reference 30.9 (11:1 p=0.006 and 10:2 p=0.039). Below FTS without structure (24.5) on R@5, and far below on R@2k (43.6).
- Heading recall is unchanged (78.4 vs 78.5) while 10% fewer nodes are produced: the removed nodes were table rows, running headers and bold body text, not headings.
- Max depth 1.4 → 1.8 comes from collection nesting (`Notes to …` → `Note N`).
