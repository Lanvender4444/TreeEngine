# TreeEngine end-to-end QA — longdoc

- documents: 48, questions: 91 (heldout 91; lookup 91)
- answer model: `deepseek-flash` (temperature 0, answer context filled to 1000, 2000 tokens from the top 50 anchors, one prompt for every strategy)
- judges: deterministic → semantic (deepseek-flash; no access to documents) → human audit
- full_context budget: 120,000 tokens
- embeddings: `fastembed:BAAI/bge-small-en-v1.5`; tokens: tiktoken cl100k_base
- judge tokens (evaluation cost, excluded below): 91,015
- retrieval code: frozen retrieval system (2026-10-11 23:19; V0.7: evidence geometry decoupled from structure geometry (treeengine/blocks: EvidenceBuilder = the structure-free paragraph blocks + offset mapping; EngineConfig.evidence_geometry stable|coupled, index_title document|section); default stable/document; coupled reproduces pre-V0.7 blocks)
- evidence geometry: stable (index title: document)
