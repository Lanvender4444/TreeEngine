# TreeEngine end-to-end QA — multires

- documents: 20, questions: 60 (test 60; cross 20, local 20, point 20)
- answer model: `deepseek-flash` (temperature 0, answer context filled to 1000, 2000 tokens from the top 50 anchors, one prompt for every strategy)
- judges: deterministic → semantic (deepseek-flash; no access to documents) → human audit
- full_context budget: 120,000 tokens
- embeddings: `fastembed:BAAI/bge-small-en-v1.5`; tokens: tiktoken cl100k_base
- judge tokens (evaluation cost, excluded below): 965,629
- retrieval code: frozen retrieval system (2026-10-13 22:57; V0.11: freeze of V0.10 retrieval for the Multi-Resolution benchmark (rtree knobs strong_blocks / min_regions / node_signals as policy fields, span resolution tags). Default (rrf + auto) outputs identical to V0.8)
- evidence geometry: stable (index title: document; pdf structure: hybrid)
