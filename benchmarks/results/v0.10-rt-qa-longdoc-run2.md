# TreeEngine end-to-end QA — longdoc

- documents: 48, questions: 91 (heldout 91; lookup 91)
- answer model: `deepseek-flash` (temperature 0, answer context filled to 1000, 2000 tokens from the top 50 anchors, one prompt for every strategy)
- judges: deterministic → semantic (deepseek-flash; no access to documents) → human audit
- full_context budget: 120,000 tokens
- embeddings: `fastembed:BAAI/bge-small-en-v1.5`; tokens: tiktoken cl100k_base
- judge tokens (evaluation cost, excluded below): 265,967
- retrieval code: frozen retrieval system (2026-10-13 18:09; V0.10: Retrieval Tree (fusion="tree": FTS/Vector/Graph activate blocks, node title BM25 + subtree centroid activate nodes, upward decaying propagation, best-first walk, adaptive resolution NodeAnchor/BlockAnchor) and the "resolution" context policy; freeze now also covers treeengine/graph and treeengine/rtree. Default (fusion rrf, context auto) outputs identical to V0.8)
- evidence geometry: stable (index title: document; pdf structure: auto)
