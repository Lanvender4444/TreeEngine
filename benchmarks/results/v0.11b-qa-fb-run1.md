# TreeEngine end-to-end QA — financebench

- documents: 84, questions: 150 (heldout 150; domain-relevant 50, metrics-generated 50, novel-generated 50)
- answer model: `deepseek-flash` (temperature 0, answer context filled to 1000, 2000 tokens from the top 50 anchors, one prompt for every strategy)
- judges: deterministic → semantic (deepseek-flash; no access to documents) → human audit
- full_context budget: 120,000 tokens
- embeddings: `fastembed:BAAI/bge-small-en-v1.5`; tokens: tiktoken cl100k_base
- judge tokens (evaluation cost, excluded below): 1,069,372
- retrieval code: frozen retrieval system (2026-10-14 00:28; V0.11b: resolution context policy - breadth before depth (hit blocks first within half the budget, then windows / sections) + a section must leave room for the next 2 hit blocks outside it; fixed on multires dev, validated on multires2. Default (rrf + auto) outputs identical to V0.8)
- evidence geometry: stable (index title: document; pdf structure: hybrid)
